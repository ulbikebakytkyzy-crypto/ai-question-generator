Основы Python

Глава 1. Переменные и типы данных

Переменная в Python — это имя, которое ссылается на значение в памяти. Объявлять тип заранее не нужно: тип определяется значением. Основные встроенные типы: int (целые числа), float (числа с плавающей точкой), str (строки), bool (логические значения True и False), list (изменяемый список), tuple (неизменяемый кортеж), dict (словарь пар «ключ — значение»). Функция type() возвращает тип объекта. Строки в Python неизменяемы: любая операция над строкой создаёт новую строку.

Глава 2. Условия и циклы

Оператор if проверяет условие и выполняет блок кода, если условие истинно. Для дополнительных проверок используются elif и else. Цикл for перебирает элементы последовательности, например for x in [1, 2, 3]. Цикл while повторяется, пока условие истинно, поэтому внутри него нужно изменять переменную условия, иначе цикл станет бесконечным. Оператор break досрочно завершает цикл, а continue переходит к следующей итерации. Функция range(n) генерирует числа от 0 до n-1.

Глава 3. Функции

Функция — это именованный блок кода, который можно вызывать многократно. Она объявляется с помощью ключевого слова def. Параметры — это имена, указанные в определении функции, а аргументы — реальные значения, которые передаются при вызове. Оператор return возвращает результат вызывающему коду; если return отсутствует, функция возвращает None. Параметры могут иметь значения по умолчанию: def greet(name, greeting="Привет"). Опасная ошибка новичков — изменяемое значение по умолчанию, например def add(x, items=[]): список создаётся один раз при определении функции и сохраняется между вызовами. Функции *args и **kwargs позволяют принимать произвольное число позиционных и именованных аргументов. Переменные, созданные внутри функции, являются локальными и недоступны снаружи; для изменения глобальной переменной используется ключевое слово global. Анонимные функции создаются с помощью lambda, например lambda x: x * 2.

Глава 4. Классы

Класс описывает шаблон объекта: его атрибуты и методы. Объект создаётся вызовом класса. Метод __init__ — конструктор, вызываемый при создании объекта. Первый параметр метода, по соглашению self, ссылается на сам объект. Наследование позволяет создать класс-потомок, который получает атрибуты и методы родителя: class Dog(Animal). Метод родителя можно вызвать через super().

Глава 5. Работа с файлами

Функция open() открывает файл. Режимы: "r" — чтение, "w" — запись с перезаписью, "a" — добавление в конец. Рекомендуется использовать конструкцию with open("data.txt", encoding="utf-8") as f: — файл автоматически закроется даже при возникновении ошибки. Метод read() читает весь файл, readline() — одну строку, а итерация по файлу читает его построчно, что экономит память для больших файлов.
