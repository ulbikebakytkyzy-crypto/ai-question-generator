# 📚 AI-генератор вопросов по учебным материалам

Загрузка PDF/TXT → извлечение текста → определение тем → генерация вопросов 5 уровней сложности
(тестовые и открытые) с ответами → проверка качества → просмотр, правка и экспорт.

**Стек:** Python · Streamlit · SQLite · LLM API (Google Gemini / Groq — бесплатно, или OpenAI) · PyMuPDF · fpdf2

## Запуск

```bash
python -m venv .venv
source .venv/bin/activate          # Windows: .venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env               # впишите OPENAI_API_KEY (или введите ключ в боковой панели)
streamlit run app.py
```

Откроется https://ai-question-generator-kaznu.streamlit.app/. Для проверки можно взять `samples/python_basics.txt` и `samples/economics_basics.txt`,
но лучше загрузить настоящие учебники (текстовые PDF).

## Запуск в облаке (Streamlit Community Cloud)

1. share.streamlit.io → **Create app** → репозиторий, ветка `main`, файл `app.py` → **Deploy**.
2. Ключ модели (бесплатно, без карты): Google Gemini — https://aistudio.google.com/apikey,
   Groq — https://console.groq.com/keys. Ключ вводится в боковой панели или добавляется в
   **Settings → Secrets**: `GEMINI_API_KEY = "..."` / `GROQ_API_KEY = "..."` / `OPENAI_API_KEY = "sk-..."`
   (ключ из Secrets остаётся на сервере и в браузер не передаётся, но расходы по нему несёт владелец).
3. База SQLite на бесплатном хостинге может обнулиться после перезапуска — используйте
   «💾 Резервная копия базы» в боковой панели (скачать JSON / восстановить).

## Как пользоваться

1. **Документ и темы** — загрузите один или несколько файлов, нажмите «Обработать»: AI найдёт 4–10 тем
   (можно добавить тему вручную).
2. **Генерация** — выберите тему, типы вопросов, уровни, количество → «Сгенерировать».
   Внизу — таблица, сколько вопросов уже есть по каждой теме и уровню.
3. **Вопросы** — режим «Просмотр» (ответ открывается по кнопке «Показать ответ») и режим
   «Редактирование и проверка»: правка, удаление, ручная проверка (вердикт + комментарий), поиск и фильтры.
4. **Мини-тест** — тестовые вопросы проверяются автоматически, открытые оценивает AI (0–2 балла с комментарием).
5. **Сравнение моделей** — две модели получают одни и те же фрагменты, модель-судья проверяет результат;
   таблица: доля вопросов без замечаний, повторы, время.
6. **Экспорт и проверка** — CSV/JSON/PDF (с ответами и бланк без ответов), отчёт ручной проверки,
   список найденных ошибок, совпадение AI-проверки с ручной, чек-лист минимальных требований защиты.

## Соответствие критериям задания

| Критерий | Где реализовано |
|---|---|
| Загрузка и обработка документов (15) | PDF/TXT, несколько файлов, сохранение в SQLite, название и превью текста — вкладка 1, `core/extract.py` |
| Определение тем (10) | AI-выделение тем + ручное добавление — `core/topics.py` |
| Генерация вопросов и ответов (25) | вопрос, ответ, объяснение, уровень, тема, страница-источник; тест и открытые — `core/generator.py` |
| Пять уровней сложности (15) | отдельные инструкции и примеры для каждого уровня, выбор уровней и количества |
| Качество и проверка (15) | удаление повторов + AI-проверка (тема, верность, уровень, один верный вариант) + ручная проверка |
| Интерфейс и сохранение (10) | Streamlit, SQLite, редактирование/удаление, резервная копия |
| Доп. задания | мини-тест, AI-проверка открытых ответов, экспорт CSV/JSON/PDF, вопросы на русском/казахском/английском, сравнение моделей |

## Как это работает

| Модуль | Что делает |
|---|---|
| `core/extract.py` | PDF (PyMuPDF) / TXT → страницы → фрагменты ≤1800 символов |
| `core/topics.py` | AI выделяет темы и ключевые слова по выборке текста |
| `core/retrieval.py` | TF-IDF поиск фрагментов, релевантных теме (без векторной БД) |
| `core/generator.py` | Промпты для 5 уровней; тест = 1 верный + 3 дистрактора, варианты перемешиваются кодом |
| `core/validator.py` | Удаление повторов (Jaccard + SequenceMatcher) и AI-проверка: тема, верность ответа, уровень, единственность верного варианта |
| `core/db.py` | SQLite (`data/app.db`): документы, фрагменты, темы, вопросы; резервная копия JSON |
| `core/grader.py` | AI-оценка открытых ответов в мини-тесте |
| `core/export_pdf.py` | экспорт в PDF (шрифт DejaVu из `fonts/` — кириллица и казахские буквы) |

Вопросы строятся **только** по найденным фрагментам текста; для каждого сохраняется страница/раздел-источник.
Вопросы со статусом ⚠️ — подозрительные по мнению AI-проверки; их нужно посмотреть вручную.

## Что подготовить к защите

1. Загрузить ≥ 2 документа и сгенерировать ≥ 25 вопросов (≥ 5 на каждом уровне).
2. Вручную проверить ≥ 15 вопросов (вкладка «Вопросы» → «Редактирование и проверка» → вердикт + комментарий).
3. Скачать «Отчёт ручной проверки» и описать найденные ошибки в презентации.
4. На защите загрузить новый документ и сгенерировать вопросы в реальном времени.

## Ограничения

- Сканированные PDF (без текстового слоя) не поддерживаются.
- Для очень больших книг темы определяются по равномерной выборке (~24 000 символов).
- Качество зависит от модели; по умолчанию `gpt-4o-mini` (меняется в боковой панели или `.env`).
- Учитывайте авторские права загружаемых материалов.
